# Extintor Clase A — HTML, CSS y DOM

Recreación del cartel usando HTML y CSS desde cero. La fotografía solo fue utilizada como referencia visual y no forma parte de la interfaz.

## Incluye

- HTML semántico
- CSS responsivo
- Figuras construidas con CSS
- Animación de llamas con `@keyframes`
- Manipulación del DOM con JavaScript
- Eventos `mouseenter`, `mouseleave`, `focus`, `blur` y `click`
- Audio al pasar el cursor sobre el ícono de fuego

## Ejecutar

Abra `index.html` con Live Server en Visual Studio Code.
